# Claude Code 指令旁欄查核

遊戲中的 CLI 旁欄用真實指令概念幫玩家理解工作階段管理，但不會真的執行 Claude Code，也不會讓指令直接改變遊戲數值。

以下用途於 2026-10-24 查核 Claude Code 官方 Commands 與 Sessions 文件；當時未在使用者電腦實跑：

| 指令 | 真實用途摘要 | 本遊戲的界線 |
|---|---|---|
| /context | 查看上下文用量 | 不等於遊戲壓力表，也不顯示真實隱藏缺陷 |
| /compact | 摘要目前對話，可指定重點 | 不保證無損、不固定省某百分比Token；本輪無遊戲付費整理效果 |
| /clear | 開始新對話 | 不等於刪專案檔、不讓遊戲時間與骰序倒退 |
| /rename | 命名工作階段 | 只是識別，不給EXP或資源 |
| /resume | 恢復或切換對話 | 不承諾重播中斷動作成功，不等於讀取遊戲存檔 |

「分析、趕工、需求筆記、快速原型、測試助手」是自然語言遊戲操作／自訂卡，不冒充官方slash command。真正 CLI 入口會隨版本、平台與環境而異。
