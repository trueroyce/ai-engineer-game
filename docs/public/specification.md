# 遊戲規格摘要

## 範圍

公開第一版包含一個「簡單待辦工具」敘事案件。它是遊戲中的模擬專案，不會真的替玩家建立待辦應用，也不會呼叫任何外部模型或服務。

## 核心循環

1. 從六種角色模板選擇工程師；數值在 UI 隱藏，但會影響事件分支。
2. 開場從三張工具卡中選一張。
3. 依案件狀態選擇有意義的工作，而不是固定三個按鈕。
4. 每次工作先解析事件，再顯示玩家 prompt、AI／客戶回應、追問與公開後果。
5. 約三分之一與三分之二進度各獲得一次三選一卡片；重複卡會融合升級。
6. 在 Token、壓力、時間與最多兩次加班限制內，形成正式交付、有限試用、原型展示、進度交接或主動停止等結果。

## 公開狀態與資訊邊界

- UI 顯示 Token、壓力、時間、目前成果、待確認問題、已知問題、驗收證據及交付缺口。
- UI 不顯示事件權重、骰值公式、隱藏缺陷、內部 function truth 或未發生分支。
- 歷史結果唯讀且免費；真正的新嘗試才消耗資源並重新解析事件。
- 相同 seed、輸入與狀態可重播；operation ID 防止重複送出刷資源或事件。

## 內容

- 六種角色模板，包含容易完成的全能戰士與高難度真初心者。
- 六種基礎工具卡，支援二級融合。
- 十二種工作、三十四個內部事件。
- 八個主要結局基底，另依 Token、壓力、時間與復原歷程加入一致的尾聲 facet。
- 完整鍵盤焦點、窄版佈局及 reduced-motion 支援。

## 唯讀 MCP

結局可匯出 `ai-engineer-game.run.v1` 公開紀錄。資料不含姓名、帳號、key、seed、事件權重或隱藏終局真相。本機 stdio MCP 僅能列出局紀錄、讀取指定局與讀取公開規則，並限制固定 `runs/` 根目錄、檔案大小、輸出大小與路徑 containment。
