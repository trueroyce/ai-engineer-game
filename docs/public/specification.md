# 遊戲規格摘要

## 範圍

公開版包含一個跨案職涯與四個已實作的模擬專案：待辦工具、CSV 整合稽核、預約／借用管理，以及上線前一天接手祖傳系統的救火案。遊戲中的 AI、sub-agent 與 NPC 協作皆為規則模擬，不會真的替玩家建立應用、啟動 agent、連線多人或呼叫外部模型與服務。

## 核心循環

1. 從六種角色模板建立獨立職涯；換角色不繼承上一個角色的 EXP 或卡庫。
2. 從大廳自由選擇案件 01、02、03 或 04；進階標示不是門鎖。
3. 依案件公開狀態選擇工作、範圍、分工與恢復方式，而不是固定預選正解。
4. 每次工作先判定成功、部分成功或失敗，再抽取對應情境，顯示玩家 prompt、AI／NPC 回應、追問與公開後果。
5. 建立角色後先起手三選一；每案約三分之一與三分之二進度各有一次三選一。獎勵可收藏新卡或融合同卡；最多三張啟用，最高二級融合。
6. 結算後 EXP、卡庫、融合與裝備跨案保存；Token、壓力與時間每案重設。正式交付、有限交付、失敗與止損都是真實結局。

## 公開狀態與資訊邊界

- UI 顯示 Token、壓力、時間、目前成果、待確認問題、已知問題、驗收證據及交付缺口。
- UI 不顯示事件權重、骰值公式、隱藏缺陷、內部 function truth 或未發生分支。
- 歷史結果唯讀且免費；真正的新嘗試才消耗資源並重新解析事件。
- 相同 seed、輸入與狀態可重播；operation ID 防止重複送出刷資源或事件。

## 內容

- 六種角色模板，包含容易完成的全能戰士與高難度真初心者。
- 十八種工具卡，依案件標示適用範圍，支援二級融合；收藏不受三張裝備上限影響。
- 案件 01 有自己的需求、實作、驗證與交付分支；案件 02、03 各有契約、協作、整合、測試與交付流程；案件 04 加入事故定位、相容 preflight、回滾、技術債與負責人範圍核准。
- 八個主要結局基底，另依 Token、壓力、時間與復原歷程加入一致的尾聲 facet。
- 完整鍵盤焦點、窄版佈局及 reduced-motion 支援。

## 唯讀 MCP

案件 01、02、03、04 結局都可保存 `ai-engineer-game.run.v1` 公開紀錄。資料不含姓名、帳號、key、seed、事件權重或隱藏終局真相。本機 stdio MCP 僅能列出局紀錄、讀取指定局與讀取公開規則，並限制固定 `runs/` 根目錄、檔案大小、輸出大小與路徑 containment。已知規則版包含 `case-01-narrative@2`／`@3`、`case-02-csv@2`、`case-03-booking@1`、`case-04-legacy@1`；未知或案件不相符版本會拒絕。

## 職涯存檔

職涯只存在相同 origin、瀏覽器與使用者設定檔的 `localStorage`。進行中案件會連同資源、亂數位置、防重送快取與兩次獎勵狀態保存；合法結算或止損後才建立下一個新 run。沒有雲端同步，也沒有職涯匯入／匯出。
